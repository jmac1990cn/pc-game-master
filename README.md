# PC Game Master
本软件是由本人借助AI工具编写的一款Windows 平台游戏管理前端。主要目的是把 Steam / Epic / 战网 / 育碧 Connect / Xbox（Game Pass）各平台的已安装游戏聚合成一个大屏启动台，支持自定义封面背景、游戏名中文化、修改器联动启动、存档目录探测、游玩时长统计、音频输出通道切换、空闲屏保与游戏攻略一键检索。与playnite等工具的区别是本工具专注于已安装好的游戏的管理，不做账号登录拉取全游戏库的方案，所有数据拉取更适合中国玩家，本人开发能力有限，仅自娱自乐，欢迎提出意见。

> 当前版本 **1.0.0**，基于 Electron 构建，MIT 协议开源。

## 主要功能

**游戏库聚合**
- 自动扫描：Steam、Epic、战网、育碧 Connect、Xbox / Game Pass
- 扫描时机：只在应用启动（或点「⟳ 刷新」）时全平台扫描一次
- 扫描结果按 id 去重；支持手动添加、按文件夹批量导入、隐藏 / 删除游戏
- 启动参数支持「预设」与「启动时询问」两种模式；模拟器游戏通过「可执行文件 = 模拟器本体 + 启动参数 （RPCS3 / Yuzu / Ryujinx / PCSX2 / Dolphin / DuckStation 等）

**启动与平台客户端**
- 启动前检测平台客户端，未运行则先拉起，再等客户端就绪后启动游戏 
- 平台游戏走平台官方启动方式，由客户端接管启动（兼容 DLC / 云存档 / 成就 / 反作弊）
- 修改器联动启动，可设启动顺序与延迟；
- 游戏窗口出现后自动切到最前端（设置可关），被抢走会自动拉回；只激活、不强制置顶霸屏

**Steam 启动项双向同步**
- 管理弹窗「启动」分页的启动选项与 Steam 自带启动项互通

**DLC 管理**
- 详情页显「🧩 DLC 管理」按钮，点开展开明细列表
- 按平台自动查询，非 Steam 但填了 appid 的按 appid 拉全量清单由用户勾选；
- DLC 资料本地缓存；可一键查找DLC补丁

**展示与自定义**
- 大屏沉浸模式 / 桌面模式双切换
- 自定义封面、大背景、徽标：本地图片或 SteamGridDB 在线选图
- 后台自动把英文游戏名换成中文，并补全缺失图片
- 游戏详情页「手柄支持」标识（完整 / 部分 / 不支持）
- 首次联网抓图后，之后所有界面全程离线，封面 / 背景 / 徽标不再消耗网络

**音频输出通道**
- 设置里可选「默认音频输出通道」
- 单款游戏可指定启动音频通道，支持「试听切换」当场验证
- 启动游戏时自动切到指定设备，**游戏退出后自动切回默认通道**
- 游戏运行期间通道不变，切到桌面 / 浏览器 / 系统重设都不改变， 只有「游戏确实退出」才还原默认通道

**游玩时长**
- 平台数据优先：解析Steam读出累计 / 近两周时长与最后游玩时间，跨机器跨重装准确
- 本地计时兜底：Epic / 战网 / 育碧 / Xbox 启动后监视进程，退出时按会话累加
- 首页排序（5 席位，同款不重复占位）：最后游玩 → 近两周最多两款 → 总时长最多两款；无记录时退化为字母序

**内存优化`
- 启动游戏后自动释放内存（卸大图 / 清会话缓存 / GC）并最小化窗口；游戏结束恢复时

**屏保**
- 空闲（默认 3 分钟，可调 1~120）后全屏遮罩轮播已安装游戏背景图，交叉淡入，任意操作立即退出
- 游戏运行中 / 窗口不可见 / 有弹窗打开时暂停计时

**游戏攻略**
- 详情页一组按钮，用中文游戏名打开外部检索：图文攻略（Bing 限定 3DM / 游民星空 / 游侠网）、B 站视频攻略、豆包答疑

**存档**
- 自动探测候选存档目录（Steam 云存档 / 我的文档 / AppData / 安装目录），一键打开

**电源菜单**
- 主界面右上角电源按钮：重启 / 关闭 PC Game Master / 关机（关机延迟 10 秒，支持取消）

## 安装与下载

从 GitHub Releases 下载最新安装包 `PC Game Master-<version>-setup.exe`

## 用户数据位置

```
%APPDATA%\PC Game Master\
├─ config.json     设置（含默认音频通道）、游戏配置（含按游戏音频通道）、信息库、
│                  本地游玩时长（playtime）、隐藏列表
├─ assets\<游戏id>\  缓存的封面 / 背景 / 徽标
├─ backgrounds\  images\
└─ logs\pc-game-master.log   诊断日志（会话开始/结束原因、音频切换与守护动作）
```
